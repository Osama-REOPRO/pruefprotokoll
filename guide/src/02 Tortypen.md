# Tortypen – gate types illustrated

The same form is used on all power-operated gates. These overviews show where each form item sits on each gate type; the table's last column names the form section.

#### Abb. 1 – Rolltor / Rollgitter
*rolling door / rolling grille (inside view)*

![[Abb-01-Rolltor.png]] ^abb-01

**Was die Zeichnung zeigt / what the drawing shows:** Inside view of a rolling door. The curtain of horizontal slats winds onto a shaft above the opening; a cut-away shows the spring pack inside the shaft. Guide rails with inlet funnels on both sides, wind hooks on the slat ends, bottom bar with safety edge, photocell across the opening. Catch device on the left shaft end, gear-motor drive with hand chain on the right, control box and lockable main switch on the wall.

![[Abb-06-Feuerschutz-Schiebetor.png]] ^abb-06

**Was die Zeichnung zeigt / what the drawing shows:** Fire sliding gate, counterweight-closing, shown held open.
