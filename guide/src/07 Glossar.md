# Glossar – abbreviations and jargon

| Begriff | Meaning |
|---|---|
| o.B. | ohne Befund – no findings (OK) |
| B. | Befund – finding / defect |
| n.v. | nicht vorhanden – not fitted |
| Bj. | Baujahr – year built |
| Fabr.-Nr. | Fabrikationsnummer – serial no. |
| Gew. | Gewicht – weight |
| Abmess. | Abmessungen – dimensions |
| flg. | flügelig – leaf (2-flg. = double-leaf) |
| T30 / T90 | fire resistance 30 / 90 min (EI2 30 / EI2 90) |
| RS / BS | Rauchschutz / Brandschutz – smoke / fire protection |
| FSA / FstA | Feststellanlage – hold-open system |
| FSZ / RSZ | Feststellanlagen- / Rauchschaltzentrale – control unit |
| HAT | Handauslösetaster – manual release button |
| ORM / ORS | optischer Rauchmelder / Rauchschalter (Hekatron) |
| THM | Türhaftmagnet – door holding magnet |
| NES / DES | Nocken- / Digitaler Endschalter – cam / encoder limit switch |
| FU | Frequenzumrichter – frequency converter (soft start/stop) |
| NHK | Nothandkurbel – emergency hand crank |
| SKS | Schließkantensicherung – safety edge |
| Panzer | rolling-door curtain |
| Torblatt / Gitter | door leaf / grille |
| Fangvorrichtung | catch device (anti-fall) |
| Sperrklinke / Sperrrad | pawl / ratchet wheel |
| Zwangstrenner | positive-break safety switch |
| Passfeder | feather key |
| Federbruch- / Seilbruchsicherung | spring-break / cable-break device |
| Schlupftür | wicket door |
| Zahnstange (Zahnst.) | gear rack |
| Gangflügel / Standflügel | active / fixed (inactive) leaf |
| Schließfolgeregler (SFR) | closing sequence selector |
| Mitnehmerklappe | carry bar / coordinator |
| Zarge | door frame |
| Bänder / Federband | hinges / spring hinge |
| abZ / aBG | German building approval (DIBt) |
| DIBt | Deutsches Institut für Bautechnik – approval body |
| Sachkundiger | competent person (gate inspection) |
| Fachkraft für Feststellanlagen | certified hold-open specialist (DIN 14677-2) |
| Betreiber | operator / owner – legally responsible |
| Totmann | hold-to-run operation |
| Mängel | defects |
| Angebot | quote / offer |
