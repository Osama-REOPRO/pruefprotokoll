# Mängel-Formulierungen – defect phrases

For the „Bemerkungen / Festgestellte Mängel“ box. Pattern: **what – where – action**.

| Deutsch | English |
|---|---|
| Ohne Mängel. / Keine Mängel festgestellt. | No defects found. |
| Akkus müssen getauscht werden. | Batteries must be replaced. |
| Rauchmelder überaltert (Bj. …), Austausch erforderlich. | Smoke detector past service life, replace. |
| Handauslösetaster fehlt / ohne Funktion. | Manual release button missing / not working. |
| Feststellanlage löst nicht aus. | Hold-open system does not release. |
| Seil rechts/links muss getauscht werden (Ø … mm, ca. … m). | Right/left cable must be replaced. |
| Feder gebrochen – Tor außer Betrieb genommen. | Spring broken – gate taken out of service. |
| Bodendichtung defekt / fehlt. | Bottom seal defective / missing. |
| Schließkantensicherung ohne Funktion. | Safety edge not working. |
| Schließkraft überschritten (gemessen … N). | Closing force exceeded (measured … N). |
| Lichtschranke verschmutzt / dejustiert. | Photocell dirty / misaligned. |
| Fangvorrichtung ausgelöst, Dämpfungsbügel tauschen. | Catch device triggered, replace damping bracket. |
| Kette gelängt, nachgespannt. / Kette erneuern. | Chain stretched, re-tensioned. / Renew chain. |
| Laufrollen verschlissen. | Rollers worn. |
| Führungsschiene verbogen (Anfahrschaden). | Guide rail bent (impact damage). |
| Notentriegelung schwergängig. | Emergency release stiff. |
| Getriebe undicht (Ölverlust). | Gearbox leaking oil. |
| Tür schließt nicht selbsttätig. | Door does not close by itself. |
| Schließfolgeregelung ohne Funktion. | Closing sequence control not working. |
| Kennzeichnungsschild fehlt. | ID plate missing. |
| Tür wird mit Keil offengehalten – unzulässig. | Door wedged open – not permitted. |
| Aufschäumende Dichtung überstrichen / beschädigt. | Intumescent seal painted over / damaged. |
| Glasscheibe gesprungen. | Glass pane cracked. |
| Mängel mündlich an Betreiber (Herr/Frau …) gemeldet. | Defects reported verbally to operator. |
| Bitte um Angebot. | Quote requested. |
| Instandsetzung umgehend erforderlich. | Repair required immediately. |
| Tor bis zur Instandsetzung außer Betrieb. | Gate out of service until repaired. |
