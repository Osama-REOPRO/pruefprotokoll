# Grundlagen – how to use this guide

## Formular ausfüllen – one mark per line, never blank

| Mark | German | Meaning |
|---|---|---|
| **o.B.** | ohne Befund | checked, OK |
| **B.** | Befund | finding / defect → explain in „Bemerkungen“ |
| **n.v.** | nicht vorhanden | part not fitted |

If a section does not apply, cross it out and write what is there instead (e.g. „Kettenrad und Kette“ → **Zahnst.** on a rack-driven sliding gate).

Item format in this guide: **Prüfen** = what to check · **o.B.** = what OK looks like · **B.** = typical defect wording · **Bild** = link to the drawing and callout number. ⚠️ **SICHERHEITSRELEVANT** = safety-critical, report immediately.

> [!warning] Before you start (DGUV 208-022)
> Tell the operator · cordon off the area · switch off at the lockable main switch (all poles) and lock it · secure the leaf against moving · never release or tension springs without proper winding bars and a secured leaf.

## Vorschriften und Intervalle – rules & intervals

| Rule | What it means in the field |
|---|---|
| ASR A1.7 (Türen und Tore) | Power-operated gates: check before first use, after major changes, then **at least once a year** by a Sachkundiger. Results recorded and kept on site. No grandfathering for old gates. |
| DGUV Information 208-022 | Practical checklist for ASR A1.7: force limits, measuring points, springs/cables/chains/shafts, isolation with lockable main switch. |
| DIN 14677-1 / -2 | Hold-open systems: operator function check **monthly** (max. 3-monthly under conditions); maintenance by a **Fachkraft für Feststellanlagen at least every 12 months**; smoke switches replaced after **8 years** at the latest. |
| EN 13241 / EN 12453 / EN 12604 / EN 12635 | Gate product standard (CE) · safety in use and force limits · mechanical safety (no free fall) · installation, use, logbook. |
| DIBt approval (abZ / aBG) | Fixes which detectors, magnets and control units may be combined on fire doors/gates. Mixing in parts from another maker voids the approval. |
| DIN 4102 / EN 1634 · DIN 18095 | T30 / T90 fire resistance (EI2 30 / 90) · RS smoke doors (S200 / Sa). |

## Kraftgrenzen an der Schließkante – force limits

| Value | Limit (EN 12453 / DGUV 208-022) |
|---|---|
| Dynamic force | ≤ 400 N (horizontal gates, opening > 500 mm: ≤ 1400 N) |
| Static force | ≤ 150 N |
| Residual force after 5 s | < 25 N |
| Measuring points | at 300 mm opening; reversing check at 50 mm |
| Manual force | should not exceed 260 N (gates) / 220 N (doors) |

Values summarised from DGUV 208-022 – check the current EN 12453 edition and the manufacturer manual. See also [[03 Formular 1 – Tore#^abb-14|Abb. 14 · SKS/Kraft]].

## Vorgehen – step by step

1. Prepare: inform operator, cordon off, isolate and lock out, secure the leaf.
2. Header: copy data from the plates, never guess. Missing plate → „Typenschild fehlt“ + B.
3. Work top to bottom, one mark per line (o.B. / B. / n.v.).
4. Run tests: limit switches, emergency stop, safety edge / photocell, force measurement (write the values), catch-device switch, hold-open release by test spray and manual button, power-failure release (battery).
5. Remarks: each B. gets one sentence – **what – where – action**; „Bitte um Angebot“ if a quote is wanted.
6. Safety-critical defect → tell the operator in person so they can take the gate out of service.
7. Both sign, hand over a copy, note the next due date.
